# Future development / التطوير القادم

Barq 27B will, God willing, continue to be developed. These are planned directions,
not shipped features, measured improvements, release dates or performance promises.

إن شاء الله سيستمر تطوير Barq 27B. البنود التالية توجهات مستقبلية، وليست قدرات
منفذة أو تحسينات مثبتة أو مواعيد إصدار ملزمة.

| Direction / الاتجاه | Evidence needed / الإثبات المطلوب |
|---|---|
| More precise tool arguments / تحسين دقة معاملات الأدوات | Held-out BFCL cases with unchanged scoring / حالات جديدة بمصحح ثابت |
| Broader instruction following / توسيع قياس الالتزام | More IFEval families, report all failures / عائلات أكثر مع حفظ الإخفاقات |
| Context and memory validation / تحقق السياق والذاكرة | Bounded retrieval and isolation tests / اختبارات محدودة للاسترجاع والعزل |
| Client compatibility / توافق العملاء | Hermes end-to-end and versioned client matrix / تحقق عملي لهرمس وإصدارات العملاء |
| Reasoning efficiency / كفاءة التفكير | Fair per-mode budgets and latency/quality tradeoffs / ميزانيات عادلة ومقارنة الزمن والجودة |

Any future weight adaptation requires separate training data, license review,
resource authorization and before/after evidence. This release does not claim it.
